# 따릉이 시간대·계절 수요 예측과 재배치

대여소별 하루 합계 대신 **시간별 대여·반납량**을 예측합니다. 출근·퇴근·심야 시간대와 봄·여름·가을·겨울의 반복 패턴을 함께 보여주고, 다음 1·2·6·12·24시간의 예상 재고와 재배치 참고량을 계산합니다.

## 1. 자료 받기

추천 원본은 [서울시 공공자전거 대여이력 OA-15182](https://data.seoul.go.kr/dataList/OA-15182/F/1/datasetView.do)입니다. 서울시는 자전거 이동 경로를 분석할 수 있는 대여 이력 원본을 제공합니다. 파일이 크므로 우선 1년치(계절별 비교용) 또는 수업에서 정한 기간을 선택하세요.

시간대별 대여 패턴을 확인하는 보조자료로 [서울시 이용정보(시간대별) OA-15245](https://data.seoul.go.kr/dataList/OA-15245/F/1/datasetView.do)를 참고할 수 있습니다. 이 데이터 설명에 대여일시·대여시간·대여소번호·대여소명이 제시되어 있습니다. **반납 대여소·반납 시각까지 이용한 재배치 분석은 대여이력 OA-15182 원본을 사용합니다.**

## 2. 큰 원본을 시간별 자료로 집계

원본 대여 이력에는 대여 시각·대여소와 반납 시각·반납 대여소가 있어야 합니다. 프로젝트의 변환기는 큰 CSV를 청크 단위로 읽고, 대여/반납을 `대여소 × 날짜 × 시간` 단위로 집계합니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python prepare_hourly_data.py --input "C:\data\bike_2025.zip" "C:\data\bike_2026_01.csv" --output "data\hourly_counts.csv"
```

`--input` 뒤에 원본 CSV 또는 ZIP 파일 경로를 여러 개 적을 수 있습니다. 변환기는 큰 원본을 청크로 읽고, 대여+반납 건수가 많은 상위 50개 대여소만 저장해 앱 업로드 크기를 줄입니다. 더 많이 저장하려면 `--top-stations 100`, 전체 대여소가 필요하면 `--top-stations 0`을 추가하세요. 변환기 기본 열 별칭은 `대여일시`, `대여대여소번호/명`, `반납일시`, `반납대여소번호/명`과 영문 이름입니다. 내려받은 파일의 헤더가 다르면 `prepare_hourly_data.py`의 별칭 목록을 원본 헤더에 맞추면 됩니다.

## 3. Streamlit 앱 실행

```powershell
streamlit run app.py
```

화면 왼쪽에서 `hourly_counts.csv`를 올리면 실제 시간대 이력으로 학습합니다. 처음에는 화면 확인용 예시 자료가 보입니다. 예시 수치는 실제 따릉이 기록이 아닙니다.

현재 재고는 서울 열린데이터광장에서 발급한 인증키로 [실시간 대여정보 OA-15493](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do)를 조회하거나, `station_name,current_bikes,capacity,latitude,longitude` 열의 재고 CSV를 올릴 수 있습니다.

## 예측과 화면 해석

- 모델은 대여소·시간·요일·계절·월 주기·출퇴근 여부·심야 여부를 입력으로 하는 Random Forest 회귀입니다.
- 실제 시간별 대여/반납량을 대여 이력에서 각각 집계해 두 값을 예측합니다.
- 화면에는 다음 1/2/6/12/24시간 대여·반납 예측, 예측 기간의 최소 재고, 부족 예상 시각, 재고 이동 참고량이 나옵니다.
- 이동 후보별로 실행 방법도 분류합니다. 부족까지 2시간 이내이거나 이동량이 6대 이상, 직선거리 1km 초과 또는 위치 정보가 없으면 **현장팀 우선**으로 표시합니다. 이동량이 1–5대이고, 직선거리 1km 이내이며, 부족까지 2시간보다 여유가 있으면 **시민 참여 후보**로 표시합니다.
- 시민 참여 분류는 앱 미션/보상 연동 전의 제안입니다. 실제 미션 발행·보상 지급이나 현장팀 배차를 수행하지 않습니다. 마일리지 규칙, 참여 시간, 대상 대여소는 운영기관의 현재 정책을 확인해 설정해야 합니다.
- 계절별 시간당 평균 대여량과 출근(07–09시)·퇴근(17–20시)·심야(22–05시) 패턴도 따로 비교합니다.
- MAE는 시간 순서로 뒤쪽 20%를 검증 구간으로 떼어 계산한 **대여량의 시간당 평균절대오차**입니다. 과거 검증 오차이며 미래 정확도를 보장하지 않습니다.
- 네 계절 패턴을 비교할 때는 최소 1년, 연도별 차이까지 다룰 때는 2년 이상을 권장합니다.

현재 모델과 확장 후보 변수의 구분, 각 변수의 공식 출처는 [변수 계획과 자료 출처](VARIABLES.md)를 확인하세요. 지금 실행 파일의 예측에는 시간·요일·계절·대여소 ID가 들어갑니다. 기상·대기질·공휴일은 공개자료가 있지만 아직 모델 입력에 연결하지 않았습니다.

이동 참고량은 `현재 자전거 + 시간별 예상 반납 − 시간별 예상 대여`를 누적해 예측 기간의 최소 보유량과 사용자가 정한 최소 재고 기준을 비교합니다. 재배치 방식은 프로젝트 데모용 우선순위 규칙으로, 도로 이동시간·차량 적재량·날씨·행사·대여소가 비어 빌리지 못한 잠재 수요는 반영하지 않습니다. 직선거리는 차량 운행거리와 다르므로 실제 운영 전 확인이 필요합니다.
