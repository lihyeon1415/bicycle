# 따릉이 수요 예측 · 대여소 재배치

서울시 따릉이 대여·반납 기록으로 대여소별 향후 1·3·7일 수요를 예측하고, 현재 자전거 재고와 비교해 대여소 간 이동 참고량을 계산하는 Streamlit 프로젝트입니다.

## 실행

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

처음 실행하면 **화면 구성 확인용 예시 데이터**가 보입니다. 예시 수치는 실제 따릉이 기록이 아니며, 예측 결과로 인용하면 안 됩니다.

## 실제 데이터 연결

1. [서울시 공공자전거 이용현황 OA-14994](https://data.seoul.go.kr/dataList/OA-14994/F/1/datasetView.do)에서 대여·반납 CSV를 내려받습니다.
2. 앱 왼쪽의 **서울시 이용현황 CSV**에 올립니다. 앱은 `대여일자`, `대여소번호` 또는 `대여소명`, `대여건수`, `반납건수` 열을 자동으로 찾습니다. 한글 CSV 인코딩(CP949/EUC-KR/UTF-8)을 차례로 처리합니다.
3. 현재 자전거 수는 [서울시 따릉이 실시간 대여정보 OA-15493](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do)의 인증키를 입력하고 **실시간 재고 불러오기**를 누릅니다. 인증키는 앱 세션에서만 사용하며 파일로 저장하지 않습니다.
4. 대여소명이 이력 파일과 실시간 API에서 다르게 표기되어 자동 연결되지 않으면 `station_name,current_bikes,capacity,latitude,longitude` 열로 정리한 재고 CSV를 올리면 됩니다. 위도·경도는 선택 열입니다.

## 계산 방식

- 대여소별 Random Forest 회귀 모델을 학습합니다. 요일·계절, 직전 1·7·14·28일의 대여 기록과 이동평균을 사용합니다.
- 최근 20% 기간을 시간 순서로 남겨 일별 대여 예측의 MAE를 계산합니다. 이 값은 선택 대여소의 과거 검증 오차이며 미래 오차를 보장하지 않습니다.
- 예측 기간의 예상 재고는 `현재 자전거 + 예상 반납 - 예상 대여`로 계산합니다.
- 사용자가 정한 최소 재고 기준보다 부족한 대여소와 여유 대여소를 연결해 이동 참고량을 제안합니다. 실제 차량 경로·운반비·차량 적재량 및 대여소가 비어 대여되지 못한 잠재 수요는 반영하지 않습니다.

## 자료 해석 시 주의

- 이용량과 실시간 재고는 서로 다른 시점의 데이터입니다. 화면에 기록 기준일을 표시하고, 이용 기록이 30일보다 오래되면 현재 재고와 합산한 종료 재고를 숨기고 오래된 기록 경고를 표시합니다.
- 대여량 기록은 실제 대여 건수입니다. 자전거가 없어 빌리지 못한 사람 수는 포함하지 않습니다.
- 공식 CSV의 열 이름이 다르면 원본 헤더를 확인하고 `standardize_history()`의 별칭 목록을 추가하면 됩니다.
